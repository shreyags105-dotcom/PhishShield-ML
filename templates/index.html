How it works

Every URL is turned into six simple numbers that the models learn from.

01

URL length

Phishing links often pad the URL with extra words and parameters.

02

Number of dots

Many dots can mean stacked subdomains imitating a real brand.

03

"@" symbol

Everything before an @ is ignored by browsers, which can hide the true destination.

04

HTTPS vs HTTP

Secure connections are more common on legitimate sites in our data.

05

IP address in URL

Real brands use domain names; a raw IP is a red flag.

06

Suspicious keywords

Words like login, verify, bank and update are used to create urgency.

Limitations & next steps

  • Precision ≈ 95%, recall ≈ 87%: when we say "phishing" we're usually right, but about 1 in 8 phishing URLs slips through.
  • Heavy reliance on HTTPS: many modern phishing sites also use HTTPS, so this signal can mislead.
  • Only 6 features: adding domain age, subdomain depth, special-character counts and URL entropy should improve recall.
  • Next steps: try XGBoost, add WHOIS/page-content features, and test on a second dataset to check generalisation.
